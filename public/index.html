Token scope guide

User Token (`xoxp-…`) is recommended for user-visible conversation discovery. It can read public channels and private conversations that the authorising user can access.

Bot Token (`xoxb-…`) can read only conversations where the installed bot has been added. It cannot use Sync user-visible conversations.

Add the same read scopes to the selected token type: public channels: channels:read, channels:history; private channels (only when needed): groups:read, groups:history; DMs (only when needed): im:read, im:history; group DMs (only when needed): mpim:read, mpim:history.

Add team:read to display the workspace name. Reinstall or re-authorise the Slack app after changing scopes.
